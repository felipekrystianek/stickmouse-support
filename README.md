# Stickmouse support

This repository is for **bug reports and questions about [Stickmouse](https://stickmouse.app)**, the app that turns a game controller into a mouse and media remote. It contains no source code.

[Open an issue](https://github.com/felipekrystianek/stickmouse-support/issues/new/choose) and pick the form that fits.

## Reporting a bug

Please include:

- **macOS version** (Apple menu → About This Mac)
- **Stickmouse version** (shown in the Stickmouse menu)
- **Controller model** and how it is connected (USB or Bluetooth), e.g. "Xbox Wireless Controller, Bluetooth"
- **Steps to reproduce**: what you did, what you expected, and what happened instead

Screenshots or a short screen recording help a lot.

## License and purchase problems

- **Activation** not working, or the license key is rejected
- **Moving to a new Mac**: deactivate on the old one if you still can, then activate on the new one. If the old Mac is gone, just ask.
- **Refunds**: within 14 days of purchase, no questions asked.

Reply to the receipt email you got from Polar, or open an issue with the "License or purchase" form. **Never post your full license key in an issue**; the last 4 characters are enough.

## Questions and ideas

Use the "Question" form for anything that isn't a bug: how to set something up, which controllers work, feature requests.
